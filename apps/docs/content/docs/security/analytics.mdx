---
title: Usage analytics
description: What the optional product analytics send, how to turn it off, and what is never sent.
icon: ChartColumn
---

OpenBot leaves product analytics off until you enable **Settings → General →
Usage analytics**. When enabled, the renderer loads `posthog-js` and sends
product events to `https://us.i.posthog.com`. PostHog is a third-party service
and sees the source IP address and standard browser/device properties of those
requests. The event names and allowed properties are defined in
[`src/lib/analytics-allowlist.ts`](../src/lib/analytics-allowlist.ts).

Autocapture, pageview capture, surveys, and remote feature flags are disabled
in the client. The app does not intentionally include chats, API keys, or file
contents in product events. The daily setup snapshot runs only while analytics
is enabled and the page is visible.

Turning the setting off stops new product events and the daily snapshot. The
choice is kept in the desktop preferences and browser storage. To clear any
previous data already held by PostHog, use that provider's privacy request
process; disabling future collection does not delete historical events.

See [`src/lib/analytics.ts`](../src/lib/analytics.ts) for the initialization,
opt-in check, and event filtering. Self-hosted server logs, AI provider traffic,
and explicitly configured integrations are separate from product analytics.
